# Ysgrif languages

Translation files for the [Ysgrif News & AI SEO](https://ysgrif.com) WordPress plugin.

- `mo/` compiled translations, which the plugin downloads
- `po/` editable sources and the `ysgrif.pot` template
- `manifest.json` lists each language with its SHA-256, so the plugin can verify a download

These are machine translations (Spanish, Japanese, Brazilian Portuguese, French) and still need a human review. Corrections are welcome as pull requests against the `.po` files.
